# AmberSadd — портфолио

Сайт-портфолио веб-дизайнера и разработчика AmberSadd (Краснодар).

**Страницы:** главная, работы с кейсами, обо мне, услуги, отзывы, контакты.

## Запуск
Один файл `index.html`: откройте в браузере или перетащите папку на [Netlify Drop](https://app.netlify.com/drop).
